02

第一步：建载体，把数据跑起来

目标是让线下顾客有一个扫码就能留下评价和反馈的地方，同时把品牌账号和视频矩阵立起来。

瓶贴 / 货架二维码→Freshjoy 网站→评价 · 问卷 · 投稿→用户数据库→Agent 分析

Freshjoy 互动网站

留存评价和反馈，挖掘用户行为、消费动机和产品意见

功能
  • 扫码打分和短评，可附照片
  • 三问小问卷：在哪买、为什么买、怎么喝（直接喝、咖啡、给孩子等）
  • 新鲜度反馈：购买时离到期还有几天
  • 咖啡与食谱投稿，作为 UGC 素材池
  • 留资换奖励（试饮券、抽奖），形成可再触达的用户名单
数据
  • 评价文本、评分、购买渠道与门店、饮用场景、购买动机、复购意向
  • Agent 按周汇总，打上动机和场景标签，回流给内容选题
注意
  • 需符合香港 PDPO、新加坡 PDPA，隐私政策和数据归属主体待品牌方确认
  • 粤语繁体、英文、简体三语

品牌账号运营体系

重新梳理 Instagram 等平台的账号定位、栏目和互动流程

平台
  • Instagram、Facebook：品牌主阵地，港新是否分号可讨论
  • TikTok、YouTube Shorts：短视频曝光
  • 小红书：覆盖香港本地用户和内地访港人群
体系
  • 统一人设和视觉，按品牌 VI 执行
  • 固定栏目：新鲜溯源、清甜口感测评、咖啡场景、0 乳糖与 A2 科普
  • 评论和私信统一回收，进入同一个用户数据库
  • 互动 SOP 和负面回应口径（如“内地奶”“到期日近”）

视频矩阵与涨粉

品牌主号加场景子号，加 KOC，起号阶段以真实素材为主

结构
  • 主号：品牌与新品信息
  • 场景子号（可考虑）：咖啡、亲子早餐、运动健身
  • KOC：港新本地小达人试饮，首批小规模
依据
  • 小红书调研里咖啡场景和 0 乳糖是口碑最集中的点 OpenClaw
  • 口感被描述为“清甜无腥”而非浓郁，测评内容宜围绕这一点 OpenClaw

曝光策略

先把线下流量导到线上，再用小额投放测试内容

打法
  • 线下触点加二维码：瓶贴、冷柜、试饮台、门店海报
  • 小预算投放测试多版内容，按数据留下表现好的方向
  • 渠道合作：惠康、百佳、FairPrice 等店内物料与会员触达
观察
  • 扫码量、网站评价数、问卷完成数、粉丝增长、互动率
  • 具体目标值建议在拿到销量和预算后与品牌方共同设定
03

第二步：批量化营销

在第一步有了数据和账号基础后，由 Agent 把“选题、生产、分发、复盘”串成循环，规模化产出内容。

用户数据与评论→Agent 选题→AI 批量生成→人工审核→多账号分发→数据回流

批量化的几条线

内容、达人、投放三条线同时放量

内容
  • 同一主题生成粤语、英文、新加坡英语等多版本
  • 科普类：新鲜链路、工艺、0 乳糖，用品牌方原始资料做底
  • 种草类：咖啡配方、早餐场景、真实用户评价改编
达人
  • KOC 从小规模扩到批量合作，素材二次授权进入素材池
投放
  • 广告语多版本 A/B 测试，所有广告语为 AI 草稿，需品牌方与法务确认后使用 草稿
把关
  • 宣称只用法务批准的口径，代言人素材只在授权范围内使用
04

第三步：线下互动，造热点

用线下活动制造打卡和分享理由，让线上内容和线下体验互相放大。以下为可讨论的方向，均为草稿。

新鲜度打卡点 草稿

在商场或渠道门店设快闪，把“从牧场到冷柜几天”做成可视化装置，拍照分享换试饮。

咖啡店联名 草稿

与港新本地咖啡店合作限定饮品，承接已有的咖啡场景口碑。

UGC 挑战赛 草稿

以网站投稿的配方或喝法为题，线上发起、线下颁奖，优质内容进入官方账号。

节点营销 草稿

结合农历新年等节点和渠道大促，做限定包装或礼盒，配合店内试饮。

病毒式传播难以预先保证，可考虑用第二步的数据先测哪类内容更容易被转发，再决定线下投入的方向。

05

Agent 整合

方案未来落在 Agent 整合架构上（架构名称待确认）。下面是各环节可由 Agent 承担的工作，人工保留审核和决策。

调研 Agent

持续抓取小红书、港新本地平台和公开网页的口碑与竞品动态。已在用：OpenClawGrokbotRavenClaude

数据 Agent

汇总网站评价、问卷和社媒评论，打动机与场景标签，每周出用户洞察。

内容 Agent

按洞察出选题、脚本、图文和短视频初稿，多语言版本，送人工审核。

分发与复盘 Agent

按账号排期发布，回收数据，标出表现好坏的内容，反馈给选题。
